# Student-owned attacks

Create attack implementations in this directory when a weekly specification
requests them. The instructor will not add or modify solver files here.

Examples of modules students will create:

~~~text
attacks/week03_keystream_reuse.py
attacks/week05_padding_oracle.py
~~~

Keep protocol handling in the challenge client supplied under course/weekXX/.
Put reusable cryptanalytic operations in educrypto when they are broadly useful,
and keep challenge-specific solve functions here.
